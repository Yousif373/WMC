
## 🌐 Aktuelles Projekt: Persönliche Webseite

Die Webseite stellt mich, meine Interessen und meine Ziele vor.

**Inhalte:**
- Über mich
- Meine Hobbys und Interessen
- Meine persönlichen Ziele
- Navigation zu den einzelnen Abschnitten

## 🎨 Verwendete Technologien

- **HTML5** – Struktur und Inhalte der Webseite
- **CSS3** – Farben, Schriftarten, Abstände und Layout
- **Git & GitHub** – Versionsverwaltung und Veröffentlichung des Codes
- **Visual Studio Code** – Entwicklungsumgebung

## 🚀 Webseite öffnen

1. Repository auf deinen Computer herunterladen oder klonen.
2. Den Ordner `WMC` in Visual Studio Code öffnen.
3. `index.html` im Browser öffnen oder die VS-Code-Erweiterung **Live Server** verwenden.

## 🎯 Lernziele

- HTML-Strukturen korrekt aufbauen
- CSS-Selektoren und Eigenschaften anwenden
- Das Box-Modell und `box-sizing: border-box` verstehen
- Farben mit CSS gestalten, unter anderem mit `rgba()`
- Abstände mit relativen Einheiten wie `rem` festlegen
- Änderungen mit Git versionieren und über GitHub verwalten
